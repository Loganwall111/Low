# Devouring Storms managed Super Duper default shaderpack

This folder is the shaderpack source imported from the user-provided
`Loganwall111/here-here` repository. Devouring Storms 1.9.176 embeds this pack
inside the mod jar and installs/selects it as the managed Iris/Oculus default
when the "Built-in Shader Pack" toggle is enabled.

The no-Iris/default Minecraft path still uses `mcsm-core-shaders/` and the
built-in Story Look resource pack; Iris/Oculus users receive this full
shaderpack as the default managed pack.

Original in-pack notices identify the shader code as Super Duper Vanilla v1.3.8,
developed by Eldeston and presented by FlameRender Studios. Keep those notices
inside any redistributed shaderpack build.
